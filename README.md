# Limit Order Book (LOB)

## 專案概述

本專案的核心學習目標，在於將《資料結構》課程中所學的樹狀結構（紅黑樹，Red-Black Tree），實際落地並應用於量化交易領域的「限價簿 (Limit Order Book, LOB)」。

*(註：本專案目前正處於底層資料結構的建構與指標邏輯除錯階段。待核心撮合邏輯與節點同步測試完成後，將持續更新系統)*
